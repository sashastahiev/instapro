# Instapro - Социальная сеть для обмена фотографиями

## Реализованная функциональность:

### Основные функции:
1. ✅ **Авторизация и регистрация** 
2. ✅ **Общая лента постов** 
3. ✅ **Лента пользователя** 
4. ✅ **Добавление постов** 
5. ✅ **Лайки** 
6. ✅ **Форматирование времени** 

### Дополнительные улучшения:
1. **Валидация форм** - проверка обязательных полей
2. **Сохранение сессии** - авторизация сохраняется после перезагрузки
3. **Защита от XSS** - экранирование HTML-тегов в постах


## Время работы:
**Первоначальная оценка:** 8-12 часов  
**Фактически затраченное время:** 30 часов
